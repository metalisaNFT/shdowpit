# THIRD-PARTY ASSETS

Every external asset used by SHDOWPIT, with license and provenance. Nothing
is imported into this repository until its license is verified from the
distribution itself (license file in the package, not just a webpage).

## Shipped in the game

### KayKit — Adventurers Character Pack 1.0 (animation data)

- **Creator:** Kay Lousberg — https://kaylousberg.com
- **Source:** official GitHub mirror
  https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Adventures-1.0
  (also distributed at https://kaylousberg.itch.io/kaykit-adventurers)
- **License:** **CC0 1.0** (public domain). Verified from `LICENSE.txt`
  inside the pack — copy vendored at `assets-src/kaykit/LICENSE.txt`:
  "This content is free to use in personal, educational and commercial
  projects." Attribution not required ("this is not mandatory") — credited
  here voluntarily. Thanks, Kay.
- **Commercial use:** yes. **Redistribution restrictions:** none (CC0).
- **Files used:** `Characters/gltf/Knight.glb` — vendored at
  `assets-src/kaykit/Knight.glb` (3.7 MB, source-of-truth for the bake; not
  shipped in the browser bundle).
- **Modifications:** 35 of its 76 animation clips are retargeted offline by
  `tools/bakeclips.mjs` onto the SHADOW PIT HUMANOID RIG (bones renamed,
  wrists folded into hands, whole skeleton conjugated 180° to face -Z, root
  motion stripped to controller-driven data, resampled to 24 Hz, quantized
  int16) and shipped as `src/anim/clips.json` (~381 KB raw, ~139 KB gzip).
  The Knight mesh, textures and other pack content are NOT used — the
  game's characters remain procedural.

## Evaluated, documented, not currently shipped

- **Quaternius — Universal Animation Library** (CC0; free tier mirrored with
  license at https://github.com/J-Ponzo/gltf-universal-animation-library) —
  backup animation source; see `docs/ANIMATION_RESEARCH.md`.
- **Kenney particle/texture packs** (CC0, https://kenney.nl) — optional VFX
  texture enrichment. Current VFX are 100% procedural (canvas-generated
  textures + geometry), so nothing external ships.
- **Mixamo (Adobe)** — royalty-free for games but account-gated and
  redistribution-restricted; **not used** (CC0 alternatives preferred).

## Everything else

All other art is generated by the game's own code (procedural rigs, meshes,
VFX textures, SVG portraits) or written for this project — no external
assets, no engine-locked marketplace content.
